# موقع مركز رحيم البيطري — Raheem Pet Care Center

موقع المركز (ماركا الشمالية، عمّان) بالعربية مع زر للتحويل إلى الإنجليزية، متجاوب مع الجوال (شريط تنقل سفلي للهاتف)، ومربوط اختيارياً بقاعدة بيانات Supabase مع لوحة إدارة للعيادة.

## هيكل الملفات

```
index.html              ← الموقع
admin.html              ← لوحة إدارة العيادة (الحجوزات، الطلبات، الرسائل)
assets/js/data.js       ← ⭐ البيانات القابلة للتعديل: الأرقام، الدوام، الخدمات، المنتجات، الأسعار، المقالات، الترجمة
assets/js/config.js     ← ⭐ رابط ومفتاح قاعدة البيانات Supabase
assets/js/db.js         ← الاتصال بقاعدة البيانات
assets/js/app.js        ← منطق الموقع: الحجز، السلة، متتبع التطعيمات، المعرض، المدونة، اللغة
assets/css/custom.css   ← أنماط إضافية
supabase/schema.sql     ← إنشاء جداول قاعدة البيانات وصلاحياتها
images/                 ← صور المركز
```

## 1) قاعدة البيانات (Supabase)

بدون إعداد، يعمل الموقع كما هو: الحجوزات تُحفظ في متصفح الزائر وتصل للعيادة عبر واتساب. بعد الربط تُحفظ الحجوزات والطلبات والرسائل في قاعدة البيانات، ويُمنع حجز الموعد نفسه مرتين.

1. أنشئ حساباً مجانياً على https://supabase.com ثم **New project** (اختر منطقة قريبة مثل Frankfurt).
2. من **SQL Editor → New query** الصق محتوى `supabase/schema.sql` كاملاً واضغط **Run**.
3. من **Project Settings → API** انسخ **Project URL** و **anon public key** وضعهما في `assets/js/config.js`.
   (مفتاح anon مخصص للنشر العلني؛ الجداول محمية بسياسات RLS: الزائر يضيف فقط ولا يقرأ بيانات غيره.)
4. **حساب الإدارة:** من **Authentication → Users → Add user** أنشئ مستخدماً ببريد العيادة وكلمة مرور، ثم شغّل في SQL Editor:
   ```sql
   insert into public.staff (user_id, name)
   select id, 'الإدارة' from auth.users where email = 'raheem.pet.center@gmail.com'
   on conflict do nothing;
   ```
5. افتح `admin.html` على الموقع وسجّل الدخول لرؤية الحجوزات والطلبات والرسائل وتغيير حالتها والاتصال بالعميل أو مراسلته على واتساب.

> ملفات حيوانات الزوار (متتبع التطعيمات) تبقى على جهاز الزائر فقط حفاظاً على الخصوصية.

## 2) النشر على GitHub Pages

الموقع منشور من هذا المستودع عبر GitHub Pages (فرع `main`، المجلد الرئيسي). أي تعديل يُرفع إلى `main` يظهر على الموقع خلال دقيقة أو اثنتين:

```bash
git add -A
git commit -m "تحديث"
git push
```

لربط نطاق خاص (مثل raheempet.com): من **Settings → Pages → Custom domain**، ثم حدّث الرابط في وسوم SEO داخل `index.html` (`canonical` و `og:image` وبيانات `ld+json`).

بعد كل تعديل على ملفات CSS/JS غيّر رقم الإصدار `?v=4` في `index.html` و `admin.html` حتى لا يعرض متصفح الزائر النسخة القديمة.
